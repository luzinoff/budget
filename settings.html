Какой ИИ отвечает

Один выбор для Бюджета, Дневника, Медкарты и Поездки в США: разборы, советы, вопросы, пояснения анализов.

Gemini сейчас отвечает

Нужен в любом случае: PDF и фото документов в Медкарте читает только Gemini. Ключ — в Google AI Studio. На платном тарифе Google не учится на ваших запросах.

DeepSeek сейчас отвечает

Дешевле Gemini в 3–6 раз, но хранит запросы в Китае и по умолчанию может учиться на них — а туда уйдут тексты дневника, финансы и выжимка медкарты. Ключ — на platform.deepseek.com, счёт пополняется заранее.

Google Диск

Client ID — один на Бюджет, Дневник, Медкарту и Поездку в США: через него каждое приложение входит в Google и хранит данные в скрытой папке вашего Диска. Секретом не является.

Как получить Client ID
  1. console.cloud.google.com → создайте проект (любое имя).
  2. APIs & Services → Library → Google Drive API → Enable.
  3. OAuth consent screen → тип External, название и своя почта; в Audience добавьте себя в Test users.
  4. Credentials → Create credentials → OAuth client ID → тип Web application; в Authorized JavaScript origins — https://luzinoff.github.io.
  5. Скопируйте Client ID сюда, затем в любом приложении нажмите «Войти и синхронизировать».

Где хранятся ключи

Изменения сохраняются сразу. Ключи ИИ лежат в памяти этого браузера и копией — в скрытой папке приложений на вашем Google Диске (файл luz-settings.json, его видят только эти приложения). На другом устройстве достаточно один раз войти в Google в любом приложении — ключи и выбор ИИ подтянутся сами. В облачные копии данных и выгрузки ключи не попадают.
